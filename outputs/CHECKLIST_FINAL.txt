================================================================
4. RUTAS DE REPRODUCCION
================================================================

Reproduccion completa desde raw:
  1. Descargar y ubicar data/raw/saber_pro_2020.xlsx ... 2024.xlsx.
  2. Instalar dependencias: pip install -r requirements.txt
  3. Ejecutar: python main.py --years 2020 2021 2022 2023 2024

Continuacion desde CSVs procesados versionados:
  - Regenerar features:
      python main.py --only 3
  - Entrenar modelos desde features.csv:
      python main.py --from-phase 4 --to-phase 6
  - Generar paper:
      python main.py --only 8

Preflight y ayuda:
  python main.py --help
  python main.py --list-phases
  python main.py --dry-run
